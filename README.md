# 🔮 Polynoob Weekly Prediction Memes

> **Official image repository for the Weekly Prediction Memes Archive**

## 📊 About

This repository contains the image assets for the **Polynoob Weekly Prediction Hub** - a curated collection of the best prediction memes from the crypto and trading community.

## 🎯 Purpose

- **Image hosting** for weekly prediction memes
- **Archive storage** for community submissions
- **CDN delivery** via GitHub Raw URLs for fast loading

## 📁 Repository Structure

```
polynoob-memes/
├── images/
│   ├── week-01/
│   ├── week-02/
│   ├── week-03/
│   └── featured/
├── thumbnails/
└── README.md
```

## 🔗 Usage

Images are served directly via GitHub Raw URLs:
```
https://raw.githubusercontent.com/[username]/[repo-name]/main/images/[filename]
```

## 📅 Weekly Schedule

- **Monday**: New week begins
- **Sunday**: Week ends
- **Archive**: Previous weeks remain accessible

## 🎨 Image Guidelines

- **Format**: PNG, JPG, WebP
- **Size**: Max 2MB per image
- **Dimensions**: Recommended 800x600px
- **Content**: Prediction-related memes only
